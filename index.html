01 / 关于我们

让技术连接真实的生产现场

大数据组针对长株潭地区的工业企业，为企业提供以产品赋能为主的解决方案。通过数据采集模块和工控机，将生产设备的各类传感器数据上传到远程服务器，再利用大数据分析技术和手段建立指标数据库与设备性能的数学模型。

由此提高设备生产质量、工作效率和产品的市场竞争力。小组学习方向主要分为 Java 后端、Web 前端，团队参与实际课题，解决当下工业企业的实际问题。
