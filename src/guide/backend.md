从 Java、数据库与 JavaWeb 基础，进入 Spring 框架及开发工具。

以下按旧版培养方案的模块顺序整理；周数为原文安排，不代表实际完成时间。

## 路线总览

| 顺序 | 知识模块    | 原定周数 |
| ---- | ----------- | -------- |
| 1    | Java        | 4 周     |
| 2    | 数据库学习  | 4 周     |
| 3    | Web基础学习 | 4 周     |
| 4    | 框架        | 4 周     |
| 5    | 其他        | 1 周     |

## 1. Java

**学习安排：** 4 周

### 学习内容

- Java基础
- 集合
- I/O
- 多线程
- Jdbc
- 网络编程

### 主要目标

熟悉Java

## 2. 数据库学习

**学习安排：** 4 周

### 学习内容

- Mysql语法:DDL DML DQL
- Redis
- influxdb
- JDBC API
- 数据库四大特性
- 数据库连接池

### 主要目标

熟悉数据库

## 3. Web基础学习

**学习安排：** 4 周

### 学习内容

- Http/TCP协议
- Servlet
- Filter
- Listener
- Tomcat
- Jsp(了解)
- Session
- Cookie

### 主要目标

熟悉JavaWeb基础

## 4. 框架

**学习安排：** 4 周

### 学习内容

- Spring：ioc，aop
- Springmvc
- Mybatis
- Springboot

### 主要目标

熟悉Spring框架

## 5. 其他

**学习安排：** 1 周

### 学习内容

- Linux、Docker、git
- Maven

### 主要目标

熟悉Linux、Git的基本操作

## 对应实践

完成相关知识模块后，查看[后端开发实践](../practice/backend.md)中的必做任务。
