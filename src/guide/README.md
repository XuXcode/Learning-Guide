本指南面向工业软件开发组新生，整理学习路线、项目实践和参考资源。建议先阅读培养目标，再选择自己的学习方向。

## 小组介绍

本组是以大数据方向进行学习，组内分2个方向，分别是前端、后端。前端又被称为web前端，前端开发就是使用HTML，CSS及JavaScript以及衍生出来的各种技术、框架、解决方案来创建web页面或APP页面呈现给用户的过程。后端则是对web应用功能的实际逻辑的实现，后端开发就是创建完整可运行的Web应用服务端程序的过程。本组对前端的要求是对于前端整体架构熟悉掌握，能够利用前端的相关技术设计出具备良好的交互功能的页面。后端则是对于后端整体的布局以及运营进行掌控，利用后端相关技术、框架等来实现后端功能的运维，能很好的实现项目的业务逻辑。

## 培养目标

通过小组的学习，学员应达到如下目标。

### 前端方向

- 目标1：学习HTML、CSS、JS三大前端语言。
- 目标2：学会Ajax实现前后端交互。
- 目标3：学习Node.js和Vue、React框架

### 后端方向

- 目标1：学习Java语言
- 目标2：学习数据库Mysql、Redis,学习JDBC实现数据库连接
- 目标3：学习JavaWeb基础
- 目标4：掌握Spring、SpringMVC、Mybatis、SpringBoot等框架
