## 让技术连接真实的生产现场

<div class="kb-about-grid">
<div class="kb-about-text">

大数据组针对长株潭地区的工业企业，为企业提供以**产品赋能**为主的解决方案。通过数据采集模块和工控机，将生产设备的各类传感器数据上传到远程服务器，再利用大数据分析技术和手段建立指标数据库与设备性能的数学模型。

由此提高设备生产质量、工作效率和产品的市场竞争力。小组学习方向主要分为 **Java 后端、Web 前端**，团队参与实际课题，解决当下工业企业的实际问题。

</div>
<div class="kb-pipeline" aria-label="工业数据技术路径">
<div><span class="kb-pipeline-index">01</span><p><strong>采集工业数据</strong><span>振动、压力、温度等传感器数据</span></p></div>
<div><span class="kb-pipeline-index">02</span><p><strong>连接设备与服务</strong><span>数据采集模块 → 工控机 → 远程服务器</span></p></div>
<div><span class="kb-pipeline-index">03</span><p><strong>分析与建模</strong><span>指标数据库 · 设备性能数学模型</span></p></div>
</div>
</div>
