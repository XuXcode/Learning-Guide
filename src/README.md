## 小组介绍

大数据组针对长株潭地区的工业企业，为企业提供以产品赋能为主的解决方案，其方式是将生产设备的各类传感器数据，如振动、压力、温度等，通过数据采集模块和工控机上传到远程服务器，利用当下热门的大数据分析技术和手段建立指标数据库和设备性能的数学模型，由此提高设备生产质量、工作效率和产品的市场竞争力。

大数据组学习方向主要分为 Java 后端、Web 前端。团队参与实际课题，解决当下工业企业的实际问题。
